# AI_Grok_OnePiece_World_Map

**Interactive 3D One Piece World Atlas**

A single-file, fully client-side 3D interactive globe of the One Piece world, built with Three.js.

## Features

- True 3D Planet (Blue Planet)
- Red Line as massive continental ring with terrain
- Grand Line + Calm Belts
- Four Blues regions
- Major islands with markers and info panels
- Search locations
- Layer toggles (Red Line, Grand Line, Calm Belt, Islands, Routes, etc.)
- OrbitControls (rotate / zoom / pan)
- Camera presets
- Atmosphere + Starfield
- Day / Night lighting
- Spoiler level control
- Responsive UI (Dark Fantasy Cartography style)

## How to use

1. Open `one_piece_world_map.html` directly in any modern browser
2. Or enable **GitHub Pages** and visit the live site

### Live Demo (GitHub Pages)

After enabling Pages on the `main` branch (root), the site will be available at:

`https://asgpro2020-boop.github.io/AI_Grok_OnePiece_World_Map/`

## Technology

- Pure HTML + CSS + JavaScript (ES2022+)
- Three.js (CDN)
- OrbitControls
- No build step, no backend, no database
